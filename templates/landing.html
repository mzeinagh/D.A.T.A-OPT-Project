D.A.T.A

Document-based Automated Toxicity Analyzer

Upload your study. Get structured answers.

D.A.T.A reads scientific and toxicology reports for you. It asks every document the same set of expert questions, guided by optimized prompts and an extraction handbook, and returns consistent, structured answers you can check against the source page.

The tool is currently optimized for the Environmental Assessment Unit at NSACB. Its flexible, scalable design allows it to be expanded to support other use cases in the future.

Example

Built for consistent, reviewable answers

Everything that usually depends on who is doing the reading is standardized, so every study is analysed the same way.

Predefined questions

A standard set of scientific questions, such as exposure route, purity, vehicle, guideline and dose, is asked of every study.

Optimized AI prompts

Carefully tuned instructions and worked examples guide the AI model toward focused, consistent responses.

Handbook-guided analysis

Structured extraction guidelines define how each answer is interpreted and presented, so results read the same across studies.

Minimal interaction with AI

No prompts to write and no chat to manage. Upload a document and the answers come back to you.

Efficient processing

Text extraction, OCR for scanned pages, and all questions run in the background, cutting hours of manual review.

Traceable to the source

Each answer shows the pages it came from, and the extracted text sits beside the original PDF for checking.

How it works

  1. 1

    Upload document

    Add a study report as a PDF. Text is extracted page by page, with OCR for scanned pages and tables.

  2. 2

    AI-powered analysis

    The predefined questions, optimized prompts and handbook guidance are applied to the relevant pages automatically.

  3. 3

    Structured answers

    Review consistent answers with their source pages, and download them as text when you're done.
